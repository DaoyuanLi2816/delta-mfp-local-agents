# Security policy

This repository contains deterministic tool-use simulations and synthetic
prompt-injection-like strings used as diagnostic data. It contains no real
credentials, external side effects, or model weights.

Please report a security issue privately through GitHub's security advisory
feature. Do not open a public issue containing credentials, private traces, or
instructions that cause real-world destructive actions.

The release scanner is a safety check, not a substitute for manual review.
